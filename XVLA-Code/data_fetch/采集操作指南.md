# UR7e 数据采集操作指南

## 前提条件

- 机器人已开机，电脑通过网线连接控制柜（IP: 192.168.1.88）
- 两个 Intel RealSense 摄像头已连接电脑（D435i + D405，USB 或 Type-C 均可）
- 关闭 RealSense Viewer 等可视化软件（否则会独占摄像头导致代码无法读取）
- 示教器上已开启自由驱动（Freedrive）模式
- 示教器上已能控制夹爪（通过 URCap 图形界面）

## 环境依赖

```bash
pip install pyrealsense2 opencv-python numpy scipy h5py rtde
```

## 启动采集

```bash
cd code/data_fetch
python collect_freedrive.py
```

## 终端交互全流程

下面以 **"抓起红色方块放到目标位置"** 为例，完整走一遍。

### 第一步：连接和初始化

```
正在连接机器人（只读模式）...
机器人已连接，当前位姿: [-0.300, -0.400, 0.200, 0.0, 3.14, 0.0]

正在启动 RealSense 摄像头...
找到 2 个 RealSense 设备:
  - Intel RealSense D405 (S/N: 419122270341)
  - Intel RealSense D435I (S/N: 254522072098)
  ▶ Intel RealSense D405 启动成功
  ▶ Intel RealSense D435I 启动成功
主视角: Intel RealSense D405 (S/N: 419122270341)
腕部视角: Intel RealSense D435I (S/N: 254522072098)
```

> 如果某个摄像头启动失败提示 `Couldn't resolve requests`，说明 USB 带宽不够，尝试把两个摄像头插到不同的 USB 接口上。

### 第二步：确认摄像头画面

脚本弹出窗口，左右并排显示两个摄像头画面：

```
正在预览摄像头画面，请确认视角分配...
按 's' 交换两个视角，按 Enter 确认继续
```

- 左边标 **"Main"** 是主视角（D435i 适合俯视/侧视全局视角）
- 右边标 **"Wrist"** 是腕部视角（D405 适合近距离特写）
- 如果左右反了，按键盘 **`s`** 交换
- 确认无误后按 **Enter** 继续

### 第三步：开始录制第一条轨迹

```
==================================================
UR7e 自由拖动采集（双 RealSense 摄像头）
==================================================
操作步骤：
  0. 示教器上进入 本地手动模式 → 开启自由驱动(Freedrive)
  1. 按住示教器背面按钮，手拖机器人
  2. 按 'g' 标记夹爪打开，按 'c' 标记闭合
  3. 按 'q' 或 ESC 结束当前轨迹
  4. 按 Enter 开始下一条
==================================================

--- 轨迹 #0 ---
按住示教器自由驱动按钮，将机器人移到起始位置
准备好后按 Enter 开始录制...
```

**这时你该做什么：**

1. 先在示教器上按住背面按钮，把机器人拖到**起始位置**（比如物体上方）
2. 确认画面中能看到物体和机械臂
3. 按 **Enter** 开始录制

### 第四步：录制过程（最关键）

按 Enter 之后，脚本开始以 30fps 连续录制，屏幕上弹出预览窗口显示实时画面和状态。

**夹爪状态是"粘滞"的：**

- 初始状态是 **CLOSED**（闭合，0.0）
- 按一次 `g` → 状态变成 **OPEN**（打开，1.0），之后所有帧都记为打开
- 按一次 `c` → 状态变成 **CLOSED**（闭合，0.0），之后所有帧都记为闭合
- **不需要一直按住**，按一次就切换，直到你再按另一个键

**一个完整的抓取过程时间线：**

```
时间 ──────────────────────────────────────────────────►

机器人动作:  移到物体上方    下降接近物体    夹住物体    抬起移动到目标    放下物体    回到初始位置
            │              │             │          │               │          │
你按的键:   (不用按)        g (打开)       c (闭合)   (不用按)         g (打开)    c (闭合)
            │              │             │          │               │          │
记录的
夹爪状态:   CLOSED         OPEN          CLOSED     CLOSED          OPEN       CLOSED
```

**具体操作步骤：**

| 时刻 | 你在示教器上做什么 | 你在键盘上按什么 | 终端提示 |
|------|-------------------|----------------|---------|
| 1 | 拖机器人到物体上方 | （不用按） | （画面显示 Gripper: CLOSED） |
| 2 | 在示教器上打开夹爪 | 按 `g` | `标记: 夹爪 → 打开` |
| 3 | 拖机器人下降到物体处 | （不用按） | （画面显示 Gripper: OPEN） |
| 4 | 在示教器上闭合夹爪抓住物体 | 按 `c` | `标记: 夹爪 → 闭合` |
| 5 | 拖机器人抬起、移到目标位置 | （不用按） | （画面显示 Gripper: CLOSED） |
| 6 | 在示教器上打开夹爪放下物体 | 按 `g` | `标记: 夹爪 → 打开` |
| 7 | 在示教器上闭合夹爪 | 按 `c` | `标记: 夹爪 → 闭合` |
| 8 | 按 `q` 结束本条轨迹 | 按 `q` | 进入保存环节 |

> **要点：你按 `c`/`g` 的时机要和示教器上实际夹爪开合的动作尽量同步。**
> 不需要精确到帧，差个零点几秒问题不大，但不要提前或延后太多。

### 第五步：结束和保存

按 `q` 后，脚本自动保存：

```
已保存: episode_0000.npz (180 帧)

继续采集下一条？(y/n):
```

- 如果帧数太少（< 30 帧），会提示 `轨迹太短（XX 帧），丢弃`
- 输入 `y` 继续采集下一条，输入 `n` 退出

### 第六步：采集下一条

输入 `y` 后：

```
--- 轨迹 #1 ---
按住示教器自由驱动按钮，将机器人移到起始位置
准备好后按 Enter 开始录制...
```

重复第三步到第五步即可。每次录制一条独立的轨迹（一次完整的抓取动作）。

### 退出

- 输入 `n` 退出
- 或按 `Ctrl+C` 随时中断

```
采集结束，共保存 5 条轨迹到 ./raw_demos
```

## 预览窗口说明

录制时屏幕上的窗口分为左右两半：

```
┌─────────────────────────┬─────────────────────────┐
│  Ep#0 F:120             │                         │
│  TCP: [-0.300,-0.400,0.200]│     Wrist              │
│  Gripper: CLOSED        │                         │
│  Main                   │                         │
│                         │                         │
│  C=close G=open | Q=stop│                         │
└─────────────────────────┴─────────────────────────┘
```

- **Ep#0** = 第几条轨迹，**F:120** = 当前第几帧
- **TCP** = 机器人末端坐标（基坐标系，单位：米）
- **Gripper: CLOSED/OPEN** = 当前记录的夹爪状态（绿色=打开，红色=闭合）

## 转换为训练数据

采集完成后，运行转换脚本：

```bash
python convert_to_hDF5.py
```

会输出：

```
找到 5 条轨迹

  [1/5] demo_0000.hdf5 — 180 帧 xyz=[-0.300,-0.400,0.200]
  [2/5] demo_0001.hdf5 — 210 帧 xyz=[-0.300,-0.400,0.200]
  ...

转换完成: 5 条轨迹, 共 950 帧
输出目录: ./training_data
```

转换脚本会将旋转表示从 RTDE 的轴角（axis-angle）转换为训练所需的欧拉角（euler XYZ），位置 xyz 不变。

## 数据格式说明

### 采集阶段（NPZ）

`raw_demos/episode_XXXX.npz` 包含：

| 字段 | 形状 | 说明 |
|------|------|------|
| `images` | (T, 256, 256, 3) uint8 | 主视角 RGB 图像 |
| `images_wrist` | (T, 256, 256, 3) uint8 | 腕部视角 RGB 图像 |
| `tcp_poses` | (T, 6) float64 | 末端位姿 [x, y, z, rx, ry, rz] 轴角 |
| `gripper` | (T,) float64 | 夹爪状态 0.0=闭合, 1.0=打开 |
| `instruction` | str | 语言指令 |
| `fps` | int | 帧率 |

### 训练阶段（HDF5）

`training_data/demo_XXXX.hdf5` 包含：

| 字段 | 形状 | 说明 |
|------|------|------|
| `observations/images/cam_high` | (T, 256, 256, 3) uint8 | 主视角 RGB 图像 |
| `observations/images/cam_wrist` | (T, 256, 256, 3) uint8 | 腕部视角 RGB 图像 |
| `puppet/end_effector` | (T, 6) float32 | [x, y, z, euler_x, euler_y, euler_z] |
| `puppet/joint_position` | (T, 7) float32 | [6个关节(填零) + gripper] |
| `language_instruction` | str (属性) | 语言指令 |

## 常见问题

**Q: 摄像头启动失败 `Couldn't resolve requests`？**
A: USB 带宽不够。把两个 RealSense 摄像头插到**不同的 USB 控制器**上（比如一个插 USB-A 口，一个插 Type-C 口）。

**Q: 摄像头检测到但画面全黑？**
A: 关闭 RealSense Viewer 等可视化软件，它们会独占摄像头。

**Q: 按了 `c`/`g` 但终端没反应？**
A: 确保预览窗口是激活状态（点一下窗口）。键盘输入只会在 OpenCV 窗口获得焦点时生效。

**Q: 采集到一半做错了怎么办？**
A: 按 `q` 结束本条。如果太短会自动丢弃；如果够长则保存了，之后手动删除 `raw_demos/episode_XXXX.npz` 即可。

**Q: 忘了按 `c`/`g` 标记夹爪怎么办？**
A: 录制结束后这条数据可能不准。建议删掉重新采集，因为夹爪状态对训练质量影响很大。

**Q: 每条轨迹应该多长？**
A: 一个完整的抓取动作通常 3-10 秒（90-300 帧）。太短（< 30 帧）会自动丢弃。

**Q: 采集多少条够训练？**
A: 建议至少 50 条相同任务的演示。同一条任务尽量保持动作一致。

**Q: 每条轨迹的初始状态要一样吗？**
A: 尽量相似但不需精确一致。先把物体和机器人放回大致相同的位置即可。

**Q: 如何更换语言指令？**
A: 修改 `collect_freedrive.py` 中的 `TASK_NAME` 变量，然后重新运行脚本。同一运行期间所有轨迹共用同一条指令。
